## 4. My Understanding

IPOS stands for Input, Processing, Output and Storage.

I understood that a computer accepts information through input devices, processes it using the CPU and memory, displays the result through output devices and saves information in storage devices.

Hardware refers to physical computer components, whereas software refers to programs and instructions.

I also learned that computer systems are used in everyday life, such as ATMs, Smart TVs and traffic signals.

## 3. Commands / tools used

## 4. My understanding
* **Staging vs. Committing**: Staging (`git add`) queues changes in the index, whereas committing (`git commit`) takes a permanent snapshot of those staged files in local history.
* **Branches & PRs**: Branches allow parallel feature development without breaking production code, while Pull Requests facilitate code review and safe integration.

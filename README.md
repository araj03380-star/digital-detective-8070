The Digital Detective 🔍

 About This Project

This repository contains my work for the [Diwali Independent Learning Assignment – The Digital Detective].

The purpose of this assignment is to understand how computers work, explore operating systems, practise Terminal commands, learn programming basics, understand number systems, and explore Git, GitHub and computer networks.

- Project: The Digital Detective
- Repository: digital-detective-8070
- Tools: macOS, Terminal, Python 3, Git, GitHub and VS Code

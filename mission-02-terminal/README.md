## 4. My Understanding
Explain in your own words:
- What is Terminal and CLI?
CLI(command line interface)- A text-based layout where you type commands to talk to    your computer.

Terminal- The window or program that lets you access and interact with the CLI.

- What is the difference between `>` and `>>`?
> - Directs output to a file and completely replaces any existing content inside it.

>> - Directs output to a file but adds it to the very end without deleting what is already there.

- What is the difference between copying and moving?
Coping - Duplicates the file, creating an identical copy in a new loaction while leaving the original file exactly where it was.

Moving - Relocates the original file to a new place or remains it,leaving no duplicates behind.

- What are flags?
Extra options or modifiers added to a command that changes how the command behaves or what data it shows.

- What does a pipe do?
Connects commands by taking the output of the first commands and sending it directly as the input for the next command.

- What is a package manager?
A built-in or third-party program like homebrew/brew that automates installing ,updating .
